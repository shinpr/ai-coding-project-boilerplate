# 安全检查模式

最后审阅时间：2026-03-21

## 稳定模式

这些模式误报率较低，可通过 grep 或静态分析检测。

### 硬编码密钥
- 在源代码中以字符串字面量形式赋值的凭据、API 密钥或令牌
- 包含嵌入密码的连接字符串
- 存储在源文件中的私钥或证书
- 检测方法：搜索赋值运算符附近的高熵字符串、常见密钥名称（`password`、`secret`、`api_key`、`token`、`private_key`）以及特定平台的令牌格式

### SQL 字符串拼接
- 通过字符串拼接或与变量插值构造的 SQL 语句
- 检测方法：搜索 SQL 关键字（`SELECT`、`INSERT`、`UPDATE`、`DELETE`）与字符串拼接运算符或包含变量引用的模板字面量组合出现的情况

### 动态代码执行
- 使用 `eval()`、`Function()`、`exec()`、`compile()` 处理动态输入
- 使用变量路径进行动态 import 或 require
- 检测方法：搜索这些函数调用中参数非静态字面量的情况

### 不安全的反序列化
- 使用 `pickle.loads()`、未指定 SafeLoader 的 `yaml.load()` 或 `marshal.loads()` 反序列化不可信输入
- `JSON.parse()` 后直接在 `eval()` 或 `Function()` 中使用
- 检测方法：搜索接受外部输入但未配置安全加载器的反序列化调用

### 路径遍历
- 未经净化处理、由用户输入构造的文件系统路径
- 请求参数流入文件读写操作的模式
- 检测方法：搜索路径参数包含请求参数、查询字符串或用户输入变量的文件操作

### CORS 通配符
- 生产环境配置中将 `Access-Control-Allow-Origin` 设为 `*`
- 配置为通配符来源的 CORS 中间件
- 检测方法：搜索配置为通配符值的 CORS 配置

### 非 TLS URL
- 源代码中嵌入的用于生产端点的 HTTP（非 TLS）URL（配置文件、测试和文档除外）
- 检测方法：在源文件中搜索 `http://` 模式，排除 localhost、配置文件、测试和文档

## 趋势敏感模式

更新时间：2026-03-21
来源：OWASP Top 10:2025、DryRun Agentic Coding Security Report（2026-03）

### AI 生成代码中的访问控制缺口
- 定义时未包含身份验证中间件的端点或路由处理程序
- 未经授权验证的资源访问操作（读取、更新、删除）
- 无需提升权限即可访问的管理性或破坏性操作
- AI 生成的代码经常遗漏身份验证中间件和授权检查——评审时应对每个路由处理程序和资源访问操作进行明确核查
- 检测方法：搜索缺少身份验证中间件的路由/端点处理程序定义，以及调用链中未经授权检查的资源操作（读取、更新、删除）

### 异常情况处理不当（OWASP A10:2025）
- 在响应中暴露内部系统细节（堆栈跟踪、数据库错误、文件路径）的错误处理程序
- 在异常发生时授予访问权限、跳过身份验证或绕过授权的错误处理程序（失效开放行为）
- 安全关键操作（身份验证、授权、加密操作）缺少错误处理
- 检测方法：搜索在响应中返回堆栈跟踪、数据库错误信息或文件路径的 catch/错误处理代码块；搜索调用 next() 或在未重新验证安全状态的情况下返回成功的 catch 代码块

### 软件供应链模式（OWASP A03:2025）
- 未固定版本号导入的依赖项
- 在安全关键功能中使用已废弃或无人维护的软件包
- 检测方法：检查依赖清单中未固定的版本号和已知的废弃软件包
