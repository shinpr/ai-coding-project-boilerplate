# 技能创建指南

用于从原始用户知识生成新技能内容的指南。

## 创建流程

在改变结构、措辞、上下文、约束或示例之前，逐字保留所提供的知识和需求。在以下三个检查点之间维持单一阶段状态。

### 步骤 1：分析

**输入**：原始用户知识（规则、模式、示例、标准）

**流程**：
1. 对内容进行分类：定义、模式、流程、标准、示例
2. 使用 BP 模式（BP-001 至 BP-009）检测问题
3. 估算规模：小（<80 行）、中（80-250 行）、大（250 行以上）
4. 判断该技能是否拥有编排/选择职责。对于这类角色，记录所需的技能引用；对于纯执行型技能，识别必须在本地具体化的执行关键上下文

**输出依据**：
- 原始需求与预期结果
- BP-001 至 BP-009 的覆盖情况
- 问题清单，包含唯一的发现 ID、严重程度、位置和引用依据
- 需保留的要求与未解决的输入项

**分析检查点**：只有在所有 BP 模式均已覆盖、每个问题都有依据、需保留的要求已明确说明、且没有未解决的输入项阻碍忠实生成时，才能继续。

### 步骤 2：生成优化后的内容

**输入**：已分类的内容 + 问题清单

**流程**：
1. 按优先级顺序应用转换：P1 → P2 → P3
2. 按照标准章节顺序组织内容：
   - 上下文/前提条件
   - 核心概念（定义、模式）
   - 流程/方法论（分步说明）
   - 输出格式/示例
   - 质量检查清单
   - 参考资料
3. **平衡检查**：
   - 过度优化：内容超出用户输入的范围 → 精简
   - 清晰度权衡：结构掩盖了要点 → 简化
4. 验证 10 项原则均通过

**输出依据**：
- 每个发现对应一条应用/跳过的处理结论
- 每处改动都可追溯到某个发现或指定的项目来源
- `SKILL.md` 候选内容体现了每一项需保留的要求

**优化检查点**：只有在每个发现都被恰好处理一次、且候选内容保持自包含并保留原意时，才能继续。

### 步骤 3：平衡

评估意图保留度、决策充分性、信息密度、约束必要性、工作量相称性和可追溯性。仅应用能解决某个已命名发现或保护某项需保留的要求的调整。

**输出**：最终的 `SKILL.md` 内容，以及其执行流程所需的、位于同一目录下的任何参考/脚本内容。

**平衡检查点**：只有在所有适用的平衡检查均通过时，才能定稿。当某个未知项阻碍某项检查时，停止并指出所需的确切依据或用户决策。

## 描述指南

对于技能 frontmatter 中的 `description` 字段：

| 规则 | 示例 |
|------|---------|
| 第三人称，动词开头 | “评估代码质量……” 而非 “本技能评估……” |
| 包含“用于/适用于/当……时”触发条件 | “用于创建测试或评审测试质量时。” |
| 目标长度约 200 字符 | 更短的描述能降低所有已加载技能的上下文压力 |
| 具体而非笼统 | “应用 9 种内容模式” 而非 “提升质量” |
| 不包含实现细节 | 描述做什么，而非怎么做 |

**核心原则**：description 是智能体的**触发机制**，而不是给人看的摘要。智能体只有在任务需要超出其基线能力的知识时才会查阅技能。description 必须传达出这个技能为何能提供智能体所欠缺的价值。

**模板**：`{动词}{做什么}，使用{项目特有的标准/模式}。用于{触发该技能的用户表述}时。`

**description 质量检查清单**：
- [ ] 包含项目特定的术语、类名或模式（区别于通用 LLM 知识）
- [ ] 使用用户实际会说的措辞（例如“添加测试”“评审错误处理”）
- [ ] 聚焦用户意图（而非技能内部机制）
- [ ] 仅由通用知识构成的技能可能是不必要的——需确认存在项目特定内容
- [ ] 一个纯技能在单独加载时仍可执行；独立加载的同级技能不是其前提条件

## 压缩与拆分

拆分之前：

1. 移除基线知识、重复内容，以及未关联到某个已观察到的重复性失败或必要约束边界的修正规则。
2. 用目的、依据和选择标准取代穷举式的分支说明。
3. 移除没有非显而易见映射关系或例外情况的示例。
4. 将可重复的确定性操作移入脚本。
5. 仅在加载条件和决策影响均明确的情况下保留条件性细节。

如果内容仍超过 400 行，将剩余的条件性细节提取到深度不超过一层的 `references/` 目录中。当正文超出 250 行的目标长度时，只有在移除某个被保留的章节会改变某个非基线决策、必要约束边界、使用方契约或已观察到的重复性失败时，这种超出才是合理的。将每条执行关键规则保留在 `SKILL.md` 中，或将加载其同目录参考资料设为明确的检查步骤；每个纯技能在没有加载同级纯技能的情况下也应保持可执行。
