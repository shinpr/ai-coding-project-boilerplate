# 后端外部资源轴

用于服务端、数据或存储工作的询问轴。

## 轴 1：数据库 Schema 来源

数据库 schema（表、列、索引、约束）的权威来源。

**AskUserQuestion 选项**：
- 仓库中的迁移文件（例如 `migrations/` 目录）
- 仓库中的 schema 文件（例如 `schema.sql`、`prisma/schema.prisma`）
- 对实时数据库进行内省的数据库 MCP 服务器
- 外部 schema 注册表（URL 或托管目录）
- 无持久化数据库
- 不适用

**后续问题（当该轴存在时）**：采集两个字段：
- **位置**：文件路径、URL 或 MCP 目标标识符
- **访问方式**：文件读取、WebFetch，或 MCP 服务器名称

当存在多个数据库时（主库、分析库、缓存库），按照 `template.md` 中的多实例规则，将每个数据库记录为单独的条目，并用数据库用途作为区分后缀。

## 轴 2：迁移历史

Schema 变更如何随时间被追踪。

**AskUserQuestion 选项**：
- 仓库中的版本化迁移文件
- ORM 管理的迁移工具（例如 Alembic、Flyway、Prisma Migrate）
- 手动维护的变更日志文档
- 无迁移追踪
- 不适用

**后续问题（当该轴存在时）**：采集两个字段：
- **位置**：目录路径或迁移工具名称
- **访问方式**：手动执行时的 CLI 命令，或迁移自动应用时的 CI 步骤 / 部署钩子名称

## 轴 3：密钥存储

凭据、API 密钥及其他机密信息的存储与访问位置。

**AskUserQuestion 选项**：
- 密钥管理服务（例如 AWS Secrets Manager、Vault、GCP Secret Manager）
- 从 `.env` 文件加载的环境变量（仅限开发环境）
- 仓库中的加密文件
- 无需机密信息
- 不适用

**后续问题（当该轴存在时）**：采集两个字段：
- **位置**：密钥管理服务名称或 MCP 目标
- **访问方式**：用于读取密钥的 MCP 服务器名称、CLI 命令或 SDK 调用

实际的密钥值存放在存储中，并在运行时从那里读取——只需记录如何访问它们即可。

## 轴 4：后台任务基础设施

异步任务如何被派发和观测。

**AskUserQuestion 选项**：
- 队列服务（例如 SQS、Pub/Sub、RabbitMQ）
- 由部署平台管理的定时 / 计划任务
- 进程内工作线程
- 无后台任务
- 不适用

**后续问题（当该轴存在时）**：采集两个字段：
- **位置**：队列名称或调度器标识符
- **访问方式**：入队命令、查看命令，或平台控制台 URL

## 自我声明阶段

在完成四个结构化轴后，统一提问一次：“除了结构化问题已覆盖的内容外，本项目还依赖其他任何后端外部资源吗？请在下一条消息中逐项列出，或回复‘无’。”

将自由格式的回答记录在“后端”领域块的“其他资源”子章节下。即使所有结构化轴都返回“不适用”，也要执行此阶段。

仅通过自我声明才会浮现的资源示例：第三方 SaaS API（支付、邮件、搜索索引）、分布式缓存服务（Redis、Memcached）、对象存储（S3、GCS）、供服务端使用的功能开关服务、可观测性平台（日志、追踪、指标）。
