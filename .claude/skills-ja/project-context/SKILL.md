# プロジェクトコンテキスト

**ステータス**: 未設定。

プロジェクトコンテキストが未設定であることを報告し、収集のために`/project-inject`を一度実行するようユーザーへ案内する。設定済みの本文には、少なくとも`## プロジェクト概要`セクションが含まれる。コマンドを利用できない、またはヒアリングを完了できない場合は、プロジェクトコンテキストが不明であることと、不足しているプロジェクト判断を具体的に報告し、推測で補わない。
